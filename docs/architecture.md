# Архитектура решения

## Сеть
Изолированная bridge-сеть `backend-net` (172.16.238.0/24). PostgreSQL доступен только внутри этой сети (порт 5432 наружу проброшен для отладки).

## Хранилище
Именованный том `postgres_pgdata` для персистентности данных.

## Безопасность
- Docker Secrets для паролей.
- pg_hba.conf разрешает доступ только из подсети Docker.
- Запуск от пользователя `postgres` (non-root).
