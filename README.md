# Курсовой проект: PostgreSQL в Docker

## Цель
Развертывание отказоустойчивой, защищённой СУБД PostgreSQL в контейнерах с соблюдением требований IaC, Git и CI/CD.

## Технологии
- PostgreSQL 17 (Alpine)
- Docker Compose
- Bash (бэкапы, healthcheck)
- GitHub Actions (линтеры, документация)
